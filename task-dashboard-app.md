# task-dashboard-app

## Goal
Build a premium-looking React(Vite)+Express fullstack task dashboard app with custom JWT auth, SQLite+Prisma, and customizable categories.

## Tasks
- [x] Task 1: Initialize backend (Express + Prisma + SQLite), setup JWT Auth → Verify: `curl` auth endpoints
- [x] Task 2: Create backend API for Tasks, Categorias, Tags → Verify: Test API endpoints functionality
- [x] Task 3: Initialize frontend (Vite React + Tailwind + Recharts + Framer Motion) → Verify: dev server runs
- [x] Task 4: Implement Login/Register UI and Auth Context → Verify: User can log in and save JWT
- [x] Task 5: Implement Dashboard View (Stats, Charts) → Verify: Displays correct data metrics with Recharts
- [x] Task 6: Implement Task Management (CRUD, Tags, Priorities, Categories) → Verify: Can add/edit/complete tasks

## Done When
- [x] User can register/login via custom JWT
- [x] User can view beautiful dashboard with their task metrics
- [x] User can manage tasks with custom categories, tags, and priorities
- [x] UI is polished with Framer Motion and modern Tailwind design
